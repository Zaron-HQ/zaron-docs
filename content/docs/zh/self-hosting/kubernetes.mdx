## 前置条件

- Kubernetes 1.19+
- Helm 3.0+
- 支持 PV 提供程序

## 安装

```bash
# Clone repo
git clone https://github.com/zaronai/Zaron.git && cd Zaron

# Generate secrets
BETTER_AUTH_SECRET=$(openssl rand -hex 32)
ENCRYPTION_KEY=$(openssl rand -hex 32)
INTERNAL_API_SECRET=$(openssl rand -hex 32)

# Install
helm install Zaron ./helm/Zaron \
  --set app.env.BETTER_AUTH_SECRET="$BETTER_AUTH_SECRET" \
  --set app.env.ENCRYPTION_KEY="$ENCRYPTION_KEY" \
  --set app.env.INTERNAL_API_SECRET="$INTERNAL_API_SECRET" \
  --namespace zaronsdk --create-namespace
```

## 关键配置

```yaml
# Custom values.yaml
app:
  replicaCount: 2
  env:
    NEXT_PUBLIC_APP_URL: "https://Zaron.yourdomain.com"
    OPENAI_API_KEY: "sk-..."

postgresql:
  persistence:
    size: 50Gi

ingress:
  enabled: true
  className: nginx
  tls:
    enabled: true
  app:
    host: Zaron.yourdomain.com
```

查看 `helm/Zaron/values.yaml` 了解所有选项。

## 外部数据库

```yaml
postgresql:
  enabled: false

externalDatabase:
  enabled: true
  host: "your-db-host"
  port: 5432
  username: "postgres"
  password: "your-password"
  database: "zaronsdk"
  sslMode: "require"
```

## 命令

```bash
# Port forward for local access
kubectl port-forward deployment/Zaron-Zaron-app 3000:3000 -n zaronsdk

# View logs
kubectl logs -l app.kubernetes.io/component=app -n zaronsdk --tail=100

# Upgrade
helm upgrade Zaron ./helm/Zaron --namespace zaronsdk

# Uninstall
helm uninstall Zaron --namespace zaronsdk
```
